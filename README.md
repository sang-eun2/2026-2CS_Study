# 2026-2 Study

2026학년도 2학기 수업 중 **코딩과 관련된 과목**의 소스 코드와 개념 정리를 모아 둔 저장소입니다.
각 폴더의 `README.md` / `NOTES.md`에 코드가 어떤 개념을 다루는지, 어떻게 실행하는지를 덧붙여 두었습니다.

| 과목 | 내용 | 언어 |
|---|---|---|
| [프로그래밍언어론](./프로그래밍언어론) | 계산기 → 파서 → 인터프리터 → 타입 검사기·배열 (언어 S) | Java |
| [시스템소프트웨어](./시스템소프트웨어) | 비트·정수 표현, 컴파일/링크/디버깅, x86-64 어셈블리 | C, NASM |
| [데이터베이스설계](./데이터베이스설계) | SQL DDL/DML, 제약조건, 정규화, PL/SQL 프로시저 | SQL (Oracle, MySQL) |

## 공개 원칙
- 개인정보(학번, 이름, 연락처)와 비밀번호·접속 정보는 올리지 않습니다. 필요한 자리는 `YOUR_DB_PASSWORD`, `1234` 같은 자리표시자로 바꿨습니다.
- 강의 슬라이드·교재 PDF는 저작권 때문에 올리지 않습니다.
- 빌드 결과물(`.class`, `.o`, 실행 파일)과 IDE 설정 파일은 제외합니다.
