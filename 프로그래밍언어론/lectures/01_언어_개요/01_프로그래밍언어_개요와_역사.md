# 01. 프로그래밍 언어 개요와 역사 (Lecture 1)

> 출처: `2026-2/프로그래밍언어론/Lecture01_Introduction.pdf`

## 한눈에 보기
- 프로그래밍 언어 = **계산을 기계도 사람도 읽을 수 있게 표현하는 표기 체계**
- 언어마다 "생각하는 방식(패러다임)"이 다르다: 명령형 / 함수형 / 논리형 / 객체지향
- 명령형 언어는 **폰 노이만 컴퓨터를 흉내 내고 추상화**하면서 발전했다
- 언어를 정의하려면 **어휘 구조 → 구문(syntax) → 의미(semantics)** 를 정해야 하고, 구현은 **컴파일러 또는 인터프리터**로 한다

---

## 1. 프로그래밍 언어란?
| 관점 | 의미 |
|---|---|
| 계산(Computation) | 데이터 조작, 텍스트 처리, 알고리즘 |
| 기계 가독성 | 효율적으로 번역·실행될 수 있어야 함 |
| 사람 가독성 | 쓰기 편하고, 컴퓨터 동작을 이해하기 쉬운 추상화 제공 |

> 💡 "언어의 구조가 사고의 범위를 정한다" — 어떤 언어를 쓰느냐에 따라 문제를 푸는 사고방식이 달라진다.

## 2. 프로그래밍 패러다임 4가지
| 패러다임 | 핵심 아이디어 | 대표 언어 |
|---|---|---|
| 명령형(Imperative) | 문제 해결을 **명령의 순서**로 기술 | C, Pascal, Ada, Python |
| 함수형(Functional) | 계산을 **수학적 함수**로 표현, 프로그램 = 함수 정의 | Lisp, Scheme, ML, Haskell |
| 논리형(Logic) | **사실과 규칙(술어 논리)** 을 기술, 증명으로 계산 | Prolog |
| 객체지향(OO) | **객체 간 상호작용(메소드 호출)** 으로 실행 | C++, Java, C#, Swift, Python |

### 함수형 언어
- 변수·대입문이 없고, 반복은 **재귀**로 표현 (전통적 루프 없음)
- 수학 기반이라 의미를 정밀하게 정의할 수 있고 기계 모델과 독립적
```ml
fun fact(n : int) : int =
    if n <= 1 then 1
    else n * fact(n-1);
```

### 논리형 언어
- `p → q` 형태의 술어 논리 기반 **선언적** 언어: "어떻게"가 아니라 "무엇"을 기술
- 루프·조건문 같은 제어 추상화가 없고 제어는 인터프리터가 담당
- 변수는 메모리 위치가 아니라 **부분 결과의 이름**
```prolog
fact(0, 1).
fact(N, V) :- N > 0, fact(N-1, V1), V is N * V1.
?- fact(3, X).
```

### 객체지향 언어
- 실세계 시뮬레이션용으로 출발
- **객체** = 속성 + 행위(메소드), **클래스** = 객체의 타입, 객체 = 클래스의 인스턴스

## 4. 폰 노이만 컴퓨터와 명령형 언어
- **저장 프로그램 방식**: 명령어와 데이터가 모두 메모리에 저장
- CPU가 **PC(Program Counter)** 가 가리키는 명령어를 하나씩 **Fetch → Decode → Execute** 반복
- 명령형 언어는 이 구조를 그대로 반영한다
  - 순차 실행 ↔ 명령어 순차 실행
  - **변수 = 메모리 위치**
  - **대입문 = 메모리 값 변경**

## 5. 추상화 (Abstraction)
구체적인 것을 요약해 더 높은 수준의 개념을 만드는 것.

| 구분 | 기본 추상화 | 구조적 추상화 |
|---|---|---|
| **데이터** | 변수(메모리 120번지 → x), 타입(int, float) | 배열(같은 타입 연속), 레코드/구조체(다른 타입 묶음) |
| **제어** | 대입문(LOAD/ADD/STORE 3줄 → `x = x+3`), goto(점프 명령) | if·switch·for·while (중첩 가능) |

- `while (c) S` 는 기계 수준에서 다음과 같다
```
L1: if (~c) GOTO L2
    S의 코드
    GOTO L1
L2: ...
```
- **프로시저(함수)**: 계산 과정을 이름으로 묶고(선언), 이름+실매개변수로 호출
- **추상 자료형(ADT)**: 데이터 + 관련 연산을 **캡슐화**한 타입 (Modula-2 모듈, Ada 패키지, C++/Java 클래스)

## 6. 언어의 정의와 구현
- **어휘 구조**: 단어(토큰)의 철자 규칙
- **구문(Syntax)**: 문장/프로그램을 만드는 규칙 → 문법(CFG, BNF)으로 기술
- **의미(Semantics)**: 문장의 의미 → 자연어 또는 수학으로 기술

| 컴파일러 | 인터프리터 |
|---|---|
| 어휘 분석 → 구문 분석 → 의미 분석 → **코드 생성** → 목적 프로그램 | 어휘 분석 → 구문 분석 → 의미 분석 → **바로 해석·실행** |
| 번역 후 실행 | 읽으면서 실행 |
