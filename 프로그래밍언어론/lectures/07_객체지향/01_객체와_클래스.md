# 01. 객체지향 언어: 객체와 클래스 (Lecture 11: Object-Oriented Languages)

> 출처: `2026-2/프로그래밍언어론/Lecture11_Object.pdf`

## 한눈에 보기
- 프로그램 = **클래스의 모음**, 실행 = **객체들이 서로 메소드를 호출**하며 상호작용
- 객체 = **속성(필드) + 행위(메소드)**, 클래스 = 객체의 타입, 객체 = 클래스의 **인스턴스**
- **캡슐화**: 관련 필드와 메소드를 묶고 내부 구현을 숨긴다 (필드는 private, 서비스 메소드는 public)
- **static**: 객체마다가 아니라 클래스에 하나 → 모든 객체가 공유
- **제네릭**: 타입 매개변수로 여러 타입에 쓰는 코드 (Java 제네릭, C++ 템플릿)

## 2. 객체와 클래스
- 예: 은행 계좌 객체 — 속성(이름, 잔고) + 행위(입금, 출금, 잔고 조회)
- **인스턴스화**: 클래스에서 객체를 만드는 과정 (Java·C++ 의 `new`)
- 객체는 **힙**에 생성, **인스턴스 변수**는 객체마다 따로, **메소드는 모든 객체가 공유**

```java
class Account {
    private String name;
    private long balance;
    Account(String name) { this.name = name; balance = 0; }            // 생성자
    Account(String name, long amount) { this.name = name; balance = amount; } // 오버로딩
    public long getBalance() { return balance; }
    public long deposit(long amount) { balance += amount; return balance; }
    public long withdraw(long amount) {
        if (amount <= balance) balance -= amount;
        else System.err.println("insufficient balance");
        return balance;
    }
}
Account acc1;                       // 참조 변수만 선언, 객체는 아직 없음
acc1 = new Account("kim");          // 객체 생성
```
### 생성자
- 클래스와 **이름이 같은** 특수 메소드, 객체 초기화용
- **반환값·반환 타입 없음**, **오버로딩 가능**

## 3. 캡슐화와 추상 자료형
- **ADT** = 데이터 + 관련 연산을 캡슐화한 타입 (Ada 패키지, Modula-2 모듈) → **클래스는 ADT 가 발전한 형태**
- **캡슐화** 이유: 내부 구현을 숨겨 외부의 잘못된 사용으로부터 보호. 객체는 **블랙박스**, 상태는 메소드로만 바꾼다

### Java 접근 제어자
| 제어자 | 접근 범위 |
|---|---|
| `public` | 어디서나 |
| `protected` | 같은 클래스 + **하위 클래스** + 같은 패키지 |
| (없음, package) | 같은 패키지 |
| `private` | 같은 클래스 안 |

- 규칙: **필드는 public 으로 두지 않는다**. 서비스를 제공하는 메소드만 public, 보조 메소드는 public 아님

## 4. static 변수와 static 메소드
| | 인스턴스 변수 | **static 변수 (클래스 변수)** |
|---|---|---|
| 메모리 | 객체마다 | 클래스에 **하나**, 모든 객체가 공유 |

- **static 메소드(클래스 메소드)**: 객체 없이 `클래스이름.메소드()` 로 호출. 그래서 **인스턴스 변수는 못 쓰고 static 변수만** 쓸 수 있다
```java
class Account {
    static int counter = 0;
    public Account() { counter++; }
    public static int getCounter() { return counter; }
}
new Account(); new Account();
Account.counter;        // 2  (인스턴스 변수였다면 각 객체마다 1)
```

## 5. 제네릭 (Generic)
- **매개변수 다형성**: 타입 매개변수로 여러 타입에 적용되는 코드 (Java 1.5 부터, 컬렉션에서 많이 사용)
- 제네릭 없이: `ArrayList` 에 아무 객체나 들어가 꺼낼 때 캐스트 필요, 잘못된 타입은 **실행 중** 오류
- 제네릭 사용: `ArrayList<Drawable>` 에 Integer 를 넣으면 **컴파일 오류** → 더 안전
```java
public class Box<T> {
    private T t;
    public void set(T t) { this.t = t; }
    public T get() { return t; }
}
Box<String> box1 = new Box<String>();
Box<Integer> box2 = new Box<>();          // 타입 생략 가능

public static <T> Box<T> boxing(T t) {     // 제네릭 메소드
    Box<T> box = new Box<T>(); box.set(t); return box;
}
Box<String> b = TestBox.<String>boxing("string");   // T 가 String 으로 대체된 버전 호출
```

## 6. Python 클래스
```python
class Account:
    counter = 0                         # 클래스 변수 (모든 객체 공유)
    def __init__(self, name):           # 초기화 메소드
        self.__name = name              # 인스턴스 변수: 선언 없이 바로 사용
        self.__balance = 0              # __ 로 시작 → private
        Account.counter += 1
    def __del__(self):                  # 객체 소멸 시
        Account.counter -= 1
    def deposit(self, amount):
        self.__balance += amount
        return self.__balance
```
- `self` = Java 의 `this`
- 접근 제어는 **이름 규칙**으로: 밑줄 없음 = public, `_name` = protected, `__name` = private
  - `my.__balance` → `AttributeError`

## 7. C++ 객체와 클래스
```cpp
class Account {
private:
    string name; long balance;
public:
    Account(string name) { this->name = name; balance = 0; }
    long deposit(long amount) { balance += amount; return balance; }
    ...
};
Account acc1("kim");                    // 변수로 선언 (스택)
Account *p = new Account("chang");      // 동적 생성, 포인터 반환 (힙)
p->deposit(400000);                     // (*p).deposit(...) 과 같음
delete p;                               // 직접 해제
```
### 템플릿 (C++ 의 제네릭)
```cpp
template <typename T>
T sum(T a, T b) { return a + b; }       // sum<int>(1,2), sum<string>("hello","world")

template <typename T>
class Box { T data; public: Box(T d) { data = d; } T get() { return data; } };
Box<int> a(10);  Box<string> b("hello");
```
