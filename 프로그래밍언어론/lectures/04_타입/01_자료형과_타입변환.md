# 01. 자료형과 타입 변환 (Lecture 6: Data Type)

> 출처: `2026-2/프로그래밍언어론/Lecture06_Types.pdf`

## 한눈에 보기
- **자료형 = 값의 집합 + 그 값에 적용 가능한 연산의 집합** (수학적으로 대수 (S, Op))
- 기본형(int, bool …) 위에 **타입 생성자**로 복합형(배열, 리스트, 레코드, 포인터 …)을 만든다
- 자동 변환은 **넓히는 변환(widening)** 만, 좁히는 변환은 **캐스트**로 명시
- 언어 분류 2축: **정적/동적 타입** × **강/약 타입**

---

## 1. 자료형의 의미
- `int x;` 의 의미 = **x ∈ Integer** (x 가 가질 수 있는 값의 집합)
- 정의 1: 자료형 = 값의 집합
- 정의 2: 자료형 = **값의 집합 + 연산의 집합**

### 기본 자료형
- 미리 정의: boolean, char, int, float, double …
- 사용자 정의 기본형 = **열거형(enum)**
```c
enum Day {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday};
enum Day today = Monday;
```

### 부분 타입 (Subtype)
- 기본 타입 값의 **부분집합**으로 정의, 기본 타입의 연산을 모두 쓸 수 있다
- Ada/Pascal 의 범위 타입: `subtype Digit is Integer range 0 .. 9;`
- C, C++, Java 에는 없다 → `if (digit > 9 || digit < 0) throw ...` 처럼 직접 검사

## 2. 복합 자료형 (타입 생성자)
| 타입 | 설명 | 예 |
|---|---|---|
| **구조체/레코드** | 서로 다른 타입 필드 묶음 | C `struct`, Pascal/Ada `record`. C++ `class` 는 여기에 연산(함수)까지 포함 |
| **배열** | 같은 타입 변수의 연속 | `int A[10];` |
| **리스트** | 여러 항목 묶음, 타입 섞임 허용, 크기 가변 | Python `[1, 'two', 3]`, Java `ArrayList` |
| **포인터** | **메모리 주소를 값으로** 갖는 타입 | `int *p;` |
| 공용체(union) | 같은 메모리를 여러 타입으로 해석 | C `union` |

### 배열 원소 주소 계산 (자주 출제)
- 1차원: `A[i]` 주소 = **base + i × sizeof(int)**
- 2차원 `int a[3][4]`
  - **행 우선(Row-major, C/C++)**: `a[i][j]` 주소 = **base + (i × 4 + j) × sizeof(int)**
  - **열 우선(Column-major, Fortran)**: 열 단위로 배치 → base + (j × 3 + i) × sizeof(int)
- Java 배열은 **객체**: 선언만으로는 생기지 않고(참조 변수일 뿐) `new int[10]` 으로 **실행 시간에 크기 결정**

### Python 리스트 슬라이싱 `list[start : end]` (end 는 포함 안 함)
```python
months = ['jan', 'feb', 'mar', 'apr', 'may']
months[1:4]  # ['feb', 'mar', 'apr']
months[1:1]  # []
months[:2]   # ['jan', 'feb']
months[2:]   # ['mar', 'apr', 'may']
```

### 포인터
| 문법 | 의미 |
|---|---|
| `T *p;` | 포인터 변수 선언 |
| `p = E;` | 포인터 변수에 주소 대입 |
| `*p = E;` | p 가 가리키는 변수에 대입 |
| `malloc(n)` | n 바이트 할당 후 시작 주소 반환 |
| `&x` | x 의 주소 |
| `*p` | p 가 가리키는 곳의 값 |

```c
int *p = malloc(4);  int y = 10;
*p = y;  *p = *p / 2;      // *p = 5
p = &y;                    // 이제 *p = 10
```

### 재귀 타입
```c
struct CharList     { char data; struct CharList  next; };  // ❌ 크기가 무한히 커짐
struct CharListNode { char data; struct CharListNode* next; }; // ✅ 포인터는 크기가 고정
```

## 3. Java 기본형 크기
| 타입 | 크기 | 범위 |
|---|---|---|
| byte | 8bit | -128 ~ 127 |
| short | 16bit | -32768 ~ 32767 |
| int | 32bit | -2,147,483,648 ~ 2,147,483,647 |
| long | 64bit | 약 ±9×10¹⁸ |
| float | 32bit | 약 ±3.4×10³⁸ |
| double | 64bit | 약 ±1.7×10³⁰⁸ |

Java 참조형: 클래스, 인터페이스, 배열

## 4. 타입 변환
| 종류 | 설명 | 예 |
|---|---|---|
| **넓히는 변환(widening, 승격)** | 더 넓은 범위로, **자동** | `double y = 99;` → 99.0. byte < short < int < long, float < double |
| **좁히는 변환(narrowing)** | 더 좁은 범위로, 대입 시 **자동으로 안 됨** | int → short, double → float |
| 예외: int **상수** | 정보 손실이 없으면 byte/short/char 로 자동 변환 | `byte b = 123;` ✅, `byte b2 = 456;` ❌, `short s2 = i;` ❌ (변수라서) |
| **캐스트 `(type) E`** | 명시적 변환, 정보 손실 가능 | `(byte) 456`, `(int) 3.14` → 3 |

## 5. 타입과 언어 분류
| | **정적 타입** (컴파일 시 변수 타입 고정) | **동적 타입** (값에 따라 실행 중 변경) |
|---|---|---|
| **강타입** (타입 오류를 엄격히 검출) | **Java**: `int x = 3.14f;` → 컴파일 오류 | **Python**: `1 + "23"` → TypeError |
| **약타입** (느슨한 규칙) | **C**: `x = y;` 경고 없이 3, `y = z;` 'A' → 65.0 | **JavaScript**: `1 + "23"` → `"123"` |

- 정적 타입 언어: Java, C, C++, FORTRAN, Pascal, Scala
- 동적 타입 언어: Perl, Python, Scheme, JavaScript (값마다 **타입 태그**를 달고 다님, `type(a)`)
- 강타입: Java, C#, Python / 약타입: C/C++, PHP, Perl, JavaScript

## 6. 실습 #4: 언어 S 에 배열 추가
```
<decl>   → ... | <type> id[n];
<stmt>   → ... | id[<expr>] = <expr>;
<factor> → ... | id[<expr>]
```
- `allocate`: 배열 Value 를 만들어 `push(id, new Value(array))`
- `V(Array)`: 배열 이름으로 배열을 찾아 `id[<expr>]` 원소 값 반환 (`arrValue()` 사용)
- `Eval(Assignment)`: 배열 원소에 대입
