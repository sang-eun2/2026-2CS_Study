## 한눈에 보기
- 식의 값은 **우선순위**와 **결합성**에 따라 달라진다 → 문법 구조로 표현
- **구조적 프로그래밍**: goto 없이 **순차·선택·반복** 3가지면 모든 계산 가능 (Böhm & Jacopini, 1966)

## 1. 식의 의미: 우선순위와 결합성
### 우선순위 (Precedence)
- 높은 우선순위 연산자가 먼저 계산된다. `a + b * c` → `a + (b * c)`
- 문법에서 **아래층 논터미널일수록 우선순위가 높다**
```
E → E + T | T
T → T * F | F
F → n | id
```
- C 언어 우선순위 순서(높음 → 낮음): 산술 `* / %` → `+ -` → 비교 `< <= > >= == !=` → 논리 `&& ||` → 조건 `?:` → 대입 `= += ...`
  - 외우는 법: **계산 → 비교 → 판단 → 저장**

### 결합성 (Associativity)
같은 우선순위 연산자가 이어질 때 계산 방향.
| 종류 | 방향 | 문법 | 예 |
|---|---|---|---|
| **좌결합** | 왼쪽 → 오른쪽 | 좌재귀 `E → E - T \| T` | 대부분의 이항 연산자. `a - b - c = (a - b) - c` |
| **우결합** | 오른쪽 → 왼쪽 | 우재귀 `E → ! E \| id` | 단항 연산자, 대입. `!!a`, `a = b = c` → `a = (b = c)` |

## 2. 구조적 프로그래밍
- goto 논쟁: Dijkstra "Goto Statement Considered Harmful"(1968) ↔ Knuth "goto 도 구조적으로 쓰면 된다"
- **기본 아이디어**: 시작점과 끝점이 하나씩인 구조적 구문만 사용 → 각 구조와 관계만 이해하면 전체를 이해할 수 있다
- **구조적 프로그래밍 정리 (Böhm & Jacopini, 1966)**: 모든 계산 가능한 함수는 다음 3가지로 표현 가능
  1. **순차**: 나열된 순서대로 실행
  2. **선택**: 상태에 따라 하나를 골라 실행 (if, switch)
  3. **반복**: 반복 실행 (while, repeat, for)
- **구문 설탕(Syntactic sugar)**: 필수 문장만으로도 되지만 편의를 위해 추가한 문장 (do-while, for, switch)

## 3. 문장의 의미: 연산 의미론 (Operational Semantics)
프로그램 실행 = 초기 상태 → … → 종료 상태로의 **상태 전이**. 문장 S 마다 `Eval(s, S) = s'` 를 정의한다.

| 문장 | 상태 전이 규칙 |
|---|---|
| 대입 `id = E` | Eval(s, id = E) = **s[id ↦ V(s, E)]** |
| 복합 `S1; S2` | Eval(s, S1;S2) = **Eval(Eval(s, S1), S2)** |
| `let T id = E in S end` | s[id ↦ V(s,E)] 에서 S 를 실행해 s'[id ↦ *] 를 얻으면, 결과는 **s' (id 항목 제거)** |
| `if E then S1 else S2` | V(s,E) = T 이면 Eval(s, S1), F 이면 Eval(s, S2) |
| `while E do S` (= L) | V(s,E) = T 이면 **Eval(Eval(s, S), L)**, F 이면 **s** |
| `read id` | n 을 읽으면 s[id ↦ n] |
| `print E` | V(s, E) 를 출력하고 상태는 그대로 s |

### 예: while 문 추적 (x 에 3 입력)
```
let int x; int y; in       s1 = {x↦0, y↦0}
  read x;                  s2 = {x↦3, y↦0}
  y = 1;                   s3 = {x↦3, y↦1}
  while (x != 1) {         V(s3, x!=1)=T → s4 = {x↦2, y↦3}
    y = y*x;               V(s4, x!=1)=T → s5 = {x↦1, y↦6}
    x = x-1;               V(s5, x!=1)=F → 결과 s5
  }
end;                       → y = 6 = 3!
```

### 예: let 중첩과 스택
```
let int x=1; in          s1 = {x↦1}           push x
  let int y=1; in        s2 = {x↦1, y↦1}      push y
    y = y + 1;           s3 = {x↦1, y↦2}
    x = x + y;           s4 = {x↦3, y↦2}
  end;                   s5 = {x↦3}           pop y
end;                     s6 = {}              pop x
```

## 4. 언어 S 인터프리터 구현
**Eval : (Statement, State) → State** — AST 를 순회하면서 문장마다 상태를 바꾼다.
```java
State Eval(Print p, State state) {
    System.out.println(V(p.expr, state));
    return state;                              // 상태 변화 없음
}

State Eval(Read r, State state) {
    if (r.id.type == Type.INT)  state.set(r.id, new Value(sc.nextInt()));
    if (r.id.type == Type.BOOL) state.set(r.id, new Value(sc.nextBoolean()));
    return state;
}

State Eval(Stmts ss, State state) {           // 복합문: 차례로 상태를 넘김
    for (Stmt stmt : ss.stmts) state = Eval(stmt, state);
    return state;
}

State Eval(If c, State state) {
    if (V(c.expr, state).boolValue()) return Eval(c.stmt1, state);
    else                              return Eval(c.stmt2, state);
}

State Eval(While l, State state) {            // 의미 규칙을 그대로 옮긴 재귀형
    if (V(l.expr, state).boolValue()) return Eval(l, Eval(l.stmt, state));
    else return state;
}
// 같은 의미의 반복형
State Eval(While l, State state) {
    while (V(l.expr, state).boolValue()) state = Eval(l.stmt, state);
    return state;
}
```
