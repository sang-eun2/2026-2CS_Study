# 01. 변수, 블록 구조, 유효범위 (Lecture 4: Variables)

> 출처: `2026-2/프로그래밍언어론/Lecture04_Variables.pdf`

## 한눈에 보기
- **선언 후 사용**이 원칙. 선언한 이름이 유효한 영역 = **유효범위(scope)**
- **정적 유효범위 규칙**: 선언된 이름은 **선언된 블록 안에서만** 유효
- 변수의 의미: 왼쪽 x = **메모리 위치(l-value)**, 오른쪽 x = **저장된 값(r-value)**
- **상태(state)** = 변수 → 값 함수. 문장은 상태를 바꾸는 함수
- 블록이 중첩되므로 상태는 **스택**으로 관리 (블록 시작 push, 끝 pop)

## 1. 변수 선언과 유효범위
언어 S 에서는 `let` 블록 안의 선언이 **지역 변수**, 밖(`<command>` 수준)의 선언이 **전역 변수**다.
```
<stmt>  → ... | let <decls> in <stmts> end;
<decls> → {<type> id [= <expr>];}
```
- 초기화하지 않은 변수는 **기본값**으로 자동 초기화
- 유효범위는 선언된 블록 안

### 같은 이름의 변수가 중첩될 때
```
let int x = 1; in          // 바깥 x
    let int y = 0; in
        y = x + 2;         // 바깥 x 사용 → y = 3
    end;
    let int x = 5; in      // 안쪽 x 가 바깥 x 를 가림
        x = x + 1;         // 안쪽 x = 6
    end;                   // 안쪽 x 사라짐
    x = x * 2;             // 바깥 x = 2
end;
```
> 💡 안쪽 블록의 같은 이름은 바깥 이름을 **가린다(hiding)**. 블록이 끝나면 다시 바깥 이름이 보인다.

## 2. 동적 타입 언어의 변수 (Python)
- 타입 선언 없이 대입하면 변수가 자동으로 생기고, 아무 타입 값이나 담을 수 있다 (Lisp, JavaScript, Python)
- **함수 안에서 전역 변수에 대입하면 지역 변수가 새로 만들어진다** → 읽기 전에 대입하면 오류
```python
percent = 20
def salePrice(price):
    percent = percent + 10     # UnboundLocalError: 지역 변수로 취급됨
    ...

def salePrice(price):
    global percent             # 전역 변수를 쓰겠다고 선언
    percent = percent + 10     # 전역 percent = 30
    return price * (1 - percent/100)
salePrice(48000)               # 33600.0
```

## 3. 블록 구조 언어
- **블록** = 관련된 선언문과 실행문을 묶은 단위
- **블록 구조 언어** = 블록 중첩을 허용하는 언어 (Algol, Pascal, Modula, Ada, C, S)

| 언어 | 블록 표기 |
|---|---|
| C, C++, Java | `{ ... }` |
| Ada | `declare ... begin ... end` |
| Pascal | 프로시저/함수 하나가 블록 |
| ML, S | `let ... in ... end` |

장점
1. 큰 프로그램을 블록으로 나눠 복잡도를 줄이고 가독성을 높인다
2. 오류가 블록 범위로 제한되어 수정·추가·삭제가 쉽다
3. 블록에서 선언한 변수는 블록 안에서만 유효하고, 블록이 끝나면 무효가 된다
4. 변수 사용과 메모리 할당 경계가 명확하다

### C 언어의 유효범위
- **선언 지점부터 그 블록 끝까지**
- 지역 변수: 선언 지점 ~ 함수 끝 / 전역 변수: 선언 지점 ~ 파일 끝

## 4. 변수의 의미와 상태
`x = x + 1;` 에서
| 위치 | 의미 |
|---|---|
| 왼쪽 x | 메모리 위치 (**l-value**) |
| 오른쪽 x | 그 위치에 저장된 값 (**r-value**) |

### 수학적 도구
- 함수 수정 `f[a ↦ b]`: x = a 이면 b, 아니면 f(x)
- **상태** `s : Identifier → Value`, 예: s = {x ↦ 1, y ↦ 2}
- 상태 갱신 `s' = s[y ↦ v]`

### 식과 문장의 의미
| 대상 | 의미 함수 | 정의 |
|---|---|---|
| 식 | `V : (State, Expr) → Value` | V(s, n) = n, V(s, id) = s(id), V(s, E1+E2) = V(s,E1) + V(s,E2) |
| 문장 | `Eval : (State, Stmt) → State` | 문장 = 상태 전이 |
| 대입문 | | Eval(s, id = E) = s[id ↦ V(s, E)] |
| 복합문 | | Eval(s, S1; S2) = Eval(Eval(s, S1), S2) |

예:
```
let int x; in            s = {x ↦ 0}
  x = 1;                 → {x ↦ 1}
  let int y; in          → {x ↦ 1, y ↦ 0}
    y = 2;               → {x ↦ 1, y ↦ 2}
    x = x + y;           → {x ↦ 3, y ↦ 2}
  end
end
```

## 5. 블록 구조에서 상태 관리 = 스택
- 블록 시작: 선언된 변수 항목을 **push**
- 블록 안 문장: 현재 유효한 변수들로 실행 (이름은 **스택 위쪽부터** 찾음 → 가장 가까운 선언이 먼저 걸림)
- 블록 끝: 그 블록 변수 항목을 **pop**
- 나중에 선언된 것이 먼저 사라짐 (**LIFO**)

## 6. 구현 (Java)
```java
class Pair  { Identifier id; Value val; }
class State extends Stack<Pair> {
    State push(Identifier id, Value val);   // 새 항목 추가
    Pair  pop();                            // 맨 위 항목 제거
    int   lookup(Identifier id);            // 위에서부터 찾아 위치 반환
    State set(Identifier id, Value val);    // 위에서부터 찾아 값 변경
    Value get(Identifier id);               // 위에서부터 찾아 값 반환
}

Value V(Expr e, State state) {              // 식의 값
    if (e instanceof Value)      return (Value) e;
    if (e instanceof Identifier) return state.get((Identifier) e);
    if (e instanceof Binary) { Binary b = (Binary) e;
        return binaryOperation(b.op, V(b.expr1, state), V(b.expr2, state)); }
    if (e instanceof Unary)  { Unary u = (Unary) e;
        return unaryOperation(u.op, V(u.expr, state)); }
}

State Eval(Assignment a, State state) {     // 대입문
    return state.set(a.id, V(a.expr, state));
}

State Eval(Let l, State state) {            // let 블록
    State s = allocate(l.decls, state);     // push
    s = Eval(l.stmts, s);
    return free(l.decls, s);                // pop
}
```
전역 변수 선언(`<command>` 가 `Decl` 인 경우)은 `allocate` 만 하고 `free` 하지 않는다.
