# Lab03: 인터프리터 (의미론)

## 무엇을 배우나
- **상태(State)**: 변수 이름과 값의 쌍 `<id, Value>`를 쌓아 두는 스택입니다.
- **의미 함수**: `Sint`는 AST 노드마다 의미를 정의합니다.
  - 식: `V(Expr e, State s)` → 값을 계산
  - 문장: `Execute(Stmt s, State s)` → 상태를 바꿈
- **블록과 유효범위**: `let` 블록에 들어가면 선언을 push(allocate)하고, 나오면 pop(free)합니다. 그래서 안쪽 블록의 같은 이름이 바깥 변수를 가립니다(정적 유효범위).

## 포인트
- `State.java`의 조회는 스택 위쪽부터 찾으므로 가장 가까운 선언이 선택됩니다.
- 대입은 새 바인딩을 만드는 것이 아니라 **이미 있는 바인딩의 값을 바꾸는 것**입니다.

## 실행
```sh
javac *.java
java Sint test/hi0.s
```
