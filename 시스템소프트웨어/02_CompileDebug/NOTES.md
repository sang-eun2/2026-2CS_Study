# 02: 컴파일과 디버깅

## 빌드 단계
| 단계 | 명령 | 결과 |
|---|---|---|
| 전처리 | `gcc -E` | `#include`, `#define`이 펼쳐진 C |
| 컴파일 | `gcc -S` | 어셈블리 `.s` |
| 어셈블 | `gcc -c` | 목적 파일 `.o` (기계어 + 심볼 테이블) |
| 링크 | `gcc a.o b.o` | 실행 파일 |

- `objdump -d`: 목적 파일을 역어셈블해 실제 기계어를 확인
- `nm`: 심볼 확인 (`T`는 정의됨, `U`는 정의되지 않음 → 링커가 찾아야 함)
- `ar rcs libops.a ops.o`: 정적 라이브러리 생성. 링크할 때 필요한 목적 파일만 복사됩니다.

## gdb 기본
```
break main   run   next / step   print 변수   info registers   x/4x &변수   bt
```
`-g` 옵션으로 컴파일해야 소스 줄과 변수 이름을 볼 수 있습니다. `-O0`이면 소스와 어셈블리가 거의 1:1로 대응해서 공부하기 좋습니다.
