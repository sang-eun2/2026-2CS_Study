# 01: 비트와 정수 표현

## bitops.c: 특정 비트만 바꾸기
```c
reg &= ~3U;   // 하위 2비트(1:0)를 0으로 지움 (마스크)
reg |= mode;  // 원하는 값으로 채움
```
**지우고(AND NOT) 채운다(OR)** 는 레지스터 필드 수정의 기본 패턴입니다. 다른 비트는 그대로 보존됩니다.
`~x`(비트 NOT)와 `!x`(논리 NOT), `&`와 `&&`가 다르다는 점도 출력으로 확인합니다.

## bytes.c: 바이트 순서
x86은 **리틀 엔디언**이라 정수의 가장 낮은 바이트가 가장 낮은 주소에 저장됩니다. `unsigned char *`로 메모리를 한 바이트씩 들여다봅니다.
(`LAST4`는 원래 학번 끝 네 자리를 넣는 자리라 공개용으로 `1234`로 바꿨습니다.)

## casts.c: 형 변환
- `short → int` 확장: 부호 비트를 복사(sign extension)해서 값이 유지됩니다.
- 같은 비트를 `unsigned`로 보면 값이 달라집니다 (`-15213` ↔ `50323`).
- `int`와 `unsigned`를 비교하면 int가 unsigned로 바뀌어 `-1 < 0U`가 **거짓**이 됩니다. `-Wsign-compare` 경고가 바로 이것입니다.

## checked_add.c: 오버플로 없이 더하기
```c
if (b >= 0 && a > INT_MAX - b) return 0;   // 양의 오버플로
if (b <  0 && a < INT_MIN - b) return 0;   // 음의 오버플로
*out = a + b; return 1;
```
부호 있는 정수 오버플로는 C에서 **정의되지 않은 동작(UB)** 이므로, 더하기 전에 범위를 먼저 검사해야 합니다.
