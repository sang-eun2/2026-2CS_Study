# 데이터통신입문 (CSC4021)

물리 계층과 데이터링크 계층을 다룹니다. 이 폴더에는 그중 **코드로 확인할 수 있는 데이터링크 계층 기능**을 기능별로 나눠 구현하고 해설합니다.
기준 환경: Python 3.8 이상, 외부 라이브러리 없음.

| 폴더 | 기능 | 강의 |
|---|---|---|
| [03_DataLink_GBN_SR](./03_DataLink_GBN_SR) | 슬라이딩 윈도우 오류·흐름 제어: Go-Back-N, Selective Repeat, 손실 채널 시뮬레이션 | L11, L12 |

각 폴더의 `README.md`는 파일 구성과 실행 방법, `NOTES.md`는 개념과 코드 해설입니다.
